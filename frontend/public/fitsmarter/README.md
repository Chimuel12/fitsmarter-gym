# human.bin

The 3D body on the Body screen: MakeHuman's base mesh (the "body" group) and a few of its targets
(male young average, universal muscle and weight, local muscle targets) and its default skeleton
and skin weights (default.mhskel, default_weights.mhw), released by the MakeHuman
community under CC0 1.0 (github.com/makehumancommunity/makehuman, LICENSE.ASSETS.md).
Built with `node scripts/fitsmarter/build-human.mjs <folder with base.obj and the .target files>`.
